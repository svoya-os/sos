# Первые шаги в СОС

> СОС в стадии пре-альфы. Здесь описана v0.1 такой, какой она задумана; до релиза команды
> ещё могут поменяться. Везде, где написано `sos`, работает и `svoya`.
>
> In English: [docs/guides/first-steps.md](../guides/first-steps.md).

## Рабочий стол за минуту

- **Панель** идёт по верхнему краю. Слева — знак азбукой Морзе (по нему открывается меню СОС),
  рабочие столы и заголовок окна. Справа — текущая задача с прогрессом, температура и память
  видеокарты, сеть, звук и батарея, раскладка, маленький осциллограф Джексона и часы. Клик по
  значкам состояния открывает **центр управления**.
- Окна плавающие, мышь работает как привык. `Super+T` включает и выключает тайлинг на текущем
  рабочем столе.
- `Super+K` показывает все сочетания клавиш.

| Клавиши | Что делают |
|---|---|
| `Super+Space` | Лаунчер: приложения, файлы, настройки; начни с `?`, чтобы спросить Джексона |
| `Super+J` | Джексон |
| `Super+V` | История буфера обмена |
| `Super+Shift+S` | Выделить область экрана: спросить Джексона, распознать текст или скопировать |
| `Super+Enter` | Терминал |
| `Super+E` | Файлы |
| `Super+Q` | Закрыть окно |
| `Super+F` | Во весь экран |
| `Super+T` | Тайлинг на этом рабочем столе |
| `Super+1` … `Super+9` | Рабочие столы |
| `Super+K` | Шпаргалка по клавишам |
| `Super+Z` | Отменить последнее изменение системы |
| `Super+Escape` | «Доктор системы» |
| `Super+L` | Заблокировать экран |

## Знакомься: Джексон

Джексон — свой парень из интернета нулевых. Может подколоть, но дело делает. Говорит
по-русски и по-английски и по умолчанию обращается на «ты» (в настройках можно переключить на
«вы»).

- **Позвать** его можно по `Super+J` или набрав в лаунчере `?` и вопрос.
- **Из терминала** — командой `j`:

  ```sh
  j найди мои датасеты
  j что занимает память видеокарты
  ```

- **Плашка маршрута** вверху панели показывает, какая модель отвечает и где она работает —
  локально или в облаке. Внизу каждого ответа видно время, токены, стоимость и то, уходили ли
  данные с компьютера.
- **Он сначала спрашивает.** Читать и искать Джексону можно без спроса. Файлы он меняет только
  после снимка, так что всё можно откатить. А всё, что выходит за пределы компьютера (отправка,
  установка из сети, незнакомый сайт), и изменения в системе — только с твоего разрешения.
  Джексон покажет, что именно сделает, и предложит три кнопки: «Разрешить один раз», «Всегда в
  этом проекте», «Отклонить».
- **Отменить** любое его действие — `Super+Z` или `sos undo`.
- **Память** Джексона — обычные Markdown-файлы, их можно читать и править: в
  `~/.local/share/svoya/jackson/memory/` или в твоём хранилище Obsidian, если ты выбрал это в
  мастере первого запуска.
- **Облачные модели по умолчанию выключены.** Чтобы подключить, добавь API-ключ провайдера (в
  мастере или позже) и смени политику маршрутов — подробности в
  [privacy.md](../guides/privacy.md#how-cloud-routing-is-shown) (на английском).

## Видеокарта

```sh
sos gpu      # проверить драйвер, CUDA или ROCm, PyTorch, Secure Boot, сон, контейнеры
sos fix      # применить безопасные исправления; сначала будет снимок
sos doctor   # полная проверка: видеокарта, диск и снимки
```

Драйвер в СОС — забота системы, а CUDA у каждого проекта своя, поэтому проекты не ломают друг
друга.

## Инструменты: модули

Модули добавляют наборы инструментов: локальные модели, Студию (картинки, видео, голос),
ML-лабораторию, Агентов, Разработку и Облачные GPU. Ничего не ставится без твоей просьбы.

```sh
sos modules list              # что есть и что уже установлено
sos install comfyui           # установить модуль; сначала будет снимок
sos modules remove comfyui    # убрать обратно (или: sos undo)
```

Профиль из мастера первого запуска — только стартовый набор, поменять его можно когда угодно.

## Модели

У всех инструментов одно хранилище моделей, `/srv/ai`, так что каждая модель скачивается один
раз.

```sh
sos models fit <модель>     # влезет ли в мою видеокарту? что разрешает лицензия?
sos models pull <модель>    # скачать в хранилище
sos models list             # что уже есть
```

Проверка лицензий учитывает твой регион и то, работаешь ли ты коммерчески. Обе настройки — в
`~/.config/svoya/svoya.toml`:

```toml
[models]
region = "EU"
commercial = true
```

## Внешний вид

```sh
sos theme apply paper     # graphite | paper | phosphor | auto
```

Или выбери тему в центре управления. «Авто» включает Графит на закате и Бумагу на рассвете —
по координатам из твоих настроек.

## Обновления и отмена

```sh
sos update          # сначала снимок, потом обновление
sos undo            # отменить последнее изменение (то же, что Super+Z)
sos snapshot list   # все снимки
```

Если после неудачного обновления не запускается даже рабочий стол, выбери в загрузочном меню
вчерашнюю систему.
