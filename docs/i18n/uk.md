# SOS — Svoya Operating System (коротко)

> SOS у стадії пре-альфа. Тут — головне; повна документація є
> [англійською](../../README.md#english) та [російською](../../README.md#по-русски). Поки що
> інтерфейс і помічник говорять англійською та російською.

**SOS** («СОС», *Svoya Operating System* — «своя операційна система») — відкритий дистрибутив
Linux для роботи зі штучним інтелектом. Під ним працює Ubuntu 26.04 LTS як невидимий рушій; усе,
що ти бачиш і чого торкаєшся, — наше: робочий стіл Svoya Shell, помічник Джексон і команда `sos`.

## Що всередині

- **Відеокарта налаштована й перевірена.** Підписані драйвери та «Доктор GPU» (`sos gpu`), який
  перевіряє зв'язку драйвер ↔ CUDA ↔ PyTorch, Secure Boot, сон і доступ до GPU з контейнерів;
  `sos fix` застосовує безпечні виправлення.
- **Джексон — помічник, який спершу питає.** Працює з локальними або хмарними моделями, запускає
  інструменти й інших агентів у пісочницях, перед ризикованим кроком показує, що саме зробить,
  веде журнал, який не можна непомітно змінити, і вміє скасовувати свої дії. Кличеш його через
  `Super+J`; з модулем голосу затисни `Super+J` і просто говори (російською або англійською, усе
  на твоєму комп'ютері).
- **Інструменти ШІ — модулями.** Нічого не нав'язуємо: `sos install comfyui` та інші, одне
  сховище моделей `/srv/ai`, а перед кожним завантаженням — перевірка, чи вміститься модель і що
  дозволяє її ліцензія.
- **Свій робочий стіл.** Клавіші з Windows працюють (`Win`, `Win+Tab`, `Alt+Tab`, `Win+D`,
  `Win+стрілки`, `Alt+F4`), є історія буфера обміну, емодзі, текст з екрана, піпетка, калькулятор
  у лаунчері, ігровий режим і теплий екран увечері.
- **Усе можна скасувати.** Знімки Btrfs перед кожним оновленням, зміною модулів і дією Джексона;
  `Super+Z` або `sos undo` відкочує останню зміну.

Обіцянка: без реклами, без облікового запису, без телеметрії; ШІ ніколи не вмикається сам;
локально за замовчуванням.

## Спробувати у віртуальній машині (хвилин 15)

1. Завантаж **[sos-26.10-amd64.iso](https://github.com/svoya-os/sos/releases/download/test/sos-26.10-amd64.iso)** (близько 1,7 ГБ, один файл, без
   реєстрації): це [тестова збірка](https://github.com/svoya-os/sos/releases/tag/test) з `main`.
2. VirtualBox: *Linux / Ubuntu (64-bit)*, 8 ГБ пам'яті, 4 ядра, «Увімкнути EFI», графіка
   *VMSVGA* без 3D, запусти з цим ISO.
3. Ти на робочому столі живої сесії. `Super+K` покаже всі сполучення клавіш; **«Install SOS»**
   у привітанні Джексона встановить систему на диск.

## Залізо

64-бітні ПК (amd64) з UEFI. NVIDIA RTX 20–50 — основна ціль; GTX 900/1000 — старий драйвер;
AMD Radeon RX 7000/9000 і Ryzen AI Max — підтримуються; Intel Arc — базово; без відеокарти все
працює, але локальний ШІ — лише з невеликими моделями.
